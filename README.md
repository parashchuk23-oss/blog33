# Modern Blog

Навчальний статичний вебсайт сучасного блогу з головною сторінкою, сторінкою публікації, пошуком матеріалів і адаптивним дизайном.

## Технології

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Запуск

Відкрийте `index.html` у браузері або запустіть локальний сервер у папці проєкту:

```bash
python3 -m http.server 8000
```

Після цього відкрийте `http://localhost:8000`.

## Перемикач теми

У навігації доступна кнопка `Dark` / `Light`, яка перемикає світлу та темну тему на обох сторінках. Вибір зберігається в `localStorage`, тому тема не скидається після оновлення сторінки. Якщо користувач ще не робив вибір, сайт враховує системну тему пристрою.
